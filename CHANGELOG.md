# Changelog

Notable externally observable changes are recorded here. Package
versions follow Semantic Versioning, independently of trace/program
schema version `1`.

## [0.0.1] — Prepared, not yet published

Initial proposed public release of Throughline.

### Included

- Deterministic, bounded authored-state trace compiler.
- Version-1 `Program` and `Trace` formats with source diagnostics and
  deterministic frame seeking.
- Five supported domains: `flow`, `bindings`, `binary`, `matrix`,
  and `callstack`.
- Optional React 19 player with keyboard playback, captions, state
  inspection, responsive layouts, reduced motion and optional sound.
- Explicitly namespaced CSS, typed ESM exports and copyable examples.
- Independent Node, TypeScript, SSR, Chromium and Vite hydration tests.
- Apache-2.0 license and 0xBUFF attribution.

**Publication pending:** the npm package is not yet released.
Source-history clearance, legal-rights review, immutable release
revision, registry staging/provenance and maintainer approval remain
separate prerequisites.
